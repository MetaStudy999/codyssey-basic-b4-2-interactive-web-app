# B4-2 — 시작 전 지식 체크

이 문서는 B4-2를 시작하기 전에 **React SPA와 원격 CRUD를 이해하기 위한 웹 기초가 준비되어 있는지** 확인하는 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B4-1
- **있으면 좋은 선행 지식:** DOM Event, `fetch`, 비동기 처리, SPA 개념, React 기초

## 자가진단

- [ ] HTML 요소와 CSS 스타일의 역할을 구분할 수 있다.
- [ ] JavaScript가 사용자 이벤트에 반응해 화면을 바꿀 수 있다는 점을 이해한다.
- [ ] DOM과 Event의 기본 의미를 알고 있다.
- [ ] HTTP 요청으로 서버의 데이터를 읽거나 저장한다는 흐름을 이해한다.
- [ ] `fetch` 또는 비동기 요청이라는 개념을 본 적이 있다.
- [ ] 한 페이지 안에서 화면이 바뀌는 SPA의 기본 개념을 설명할 수 있다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- HTML/CSS/JavaScript 기본 흐름이 낯설다면 B4-1을 먼저 수행하거나 관련 Step만 복습하면 좋습니다.
- React 자체가 처음이어도 B4-2에서 학습할 수 있으므로 시작을 막지 않습니다.

> **B4-1 CLEAR는 필수 조건이 아닙니다.** 웹 기본 구조를 이미 이해한다면 바로 B4-2에 진입할 수 있습니다.
